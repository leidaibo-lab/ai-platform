# 上下文记忆评测指标

## 核心指标

| 指标 | 计算方式 | 失败含义 |
| --- | --- | --- |
| 纠正事实准确率 | 最新 active 值正确案例数 / 纠正案例总数 | 旧值未废弃或新值未召回 |
| 旧事实泄漏率 | 最终回答仍使用旧值案例数 / 纠正案例总数 | superseded 内容污染上下文 |
| 实体隔离准确率 | 主实体和干扰实体均正确案例数 / 隔离案例总数 | 相似实体被错误合并 |
| 任务状态准确率 | 状态正确任务数 / 被检查任务总数 | pending/completed/cancelled 漂移 |
| 来源有效率 | 指向真实原始消息的来源 ID 数 / 总来源 ID 数 | 记忆不可追溯或来源伪造 |
| Checkpoint 成功率 | compacted checkpoint 数 / 计划 checkpoint 数 | 压缩失败、冲突未恢复或水位异常 |

## 运行指标

真实模型评测同时记录：

- 输入、输出和总 token。
- 按实际模型单价估算的总费用和单案例费用。
- 平均延迟、P50、P95 和最大延迟。
- 实际模型、模型别名、Prompt 版本和 fixture 版本。

## 建议门槛

首版发布门槛建议为：纠正事实准确率不低于 95%，实体隔离准确率不低于 98%，旧事实泄漏率低于 1%，来源有效率等于 100%。样本量不足 30 时只报告观察结果，不把百分比作为发布结论。

确定性脚本模型只用于验证执行链路和判分逻辑，不计入真实模型准确率基线。
