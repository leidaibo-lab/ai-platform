# 验证案例与记录

仅在验证技能或调整核心流程时读取。以下材料用于检查判断与产物，不是目标项目的业务政策。原始业务文档不随技能分发；复用时可在隔离目录用下列脱敏条件重建案例。

## 执行方式

执行者接收用户任务、技能和最小原始材料，完成实际需求或修改；评审者检查业务条件、关联同步、范围控制和证据。先完成产物，再核对判据。独立执行条件具备且已获授权时，可由未参与设计的执行者完成，不向其提供预期答案。

## 代表性案例

| 任务与原始材料 | 评审判据 |
| --- | --- |
| 根据已确认的角色、权限和范围资料整理人员分配需求；内部已有分配行为但正式交付缺页 | 补齐有依据的阅读单元并同步入口及验收；不新增身份合并政策或无关页面 |
| 权威规则允许保留原停用关联，字段表及验收却要求编辑其他字段前替换该值 | 同步正文、字段和验收，分别推演原关联保留、新选择停用值、提交前选项停用；不只改一句 |
| 用户要求纠正字典入口授权；权限目录独立定义字典查看和部门查看，旧页面混用两项 | 修正字典入口并检查查询按钮和验收，部门页条件保留；不扩展成权限系统重写 |
| 正式PRD混入人工试点评估安排，配套已有指标口径 | 将系统行为与人工效果评估分开；不新增统计页面，不删除已有质量要求 |
| “负责人可以调整业务记录”，未说明调整字段、范围或状态条件 | 先查已有证据，提出有理由的范围推荐及必要问题；继续已确定工作，不自行扩大授权 |
| 导出预检通过，但本期页面未进入正式输出，引用的原型也不存在 | 检查实际交付并补已有定义，处理失效引用；不能凭预检通过声称可交付 |
| 仅要求统一两个已定义字段的表头 | 完成局部修正及相关检查；不全项目重写、不索要无关业务决策 |

## 1.0.0入仓验证（2026-11-03）

### 实际任务回放

任务来自已有产品项目的字典页面授权冲突。使用真实权限目录、历史页面正文及当前验收附件，在隔离副本完成审查与修正；本节仅记录脱敏后的行为及证据，不分发项目文档。

| 项目 | 观察结果 |
| --- | --- |
| 输入冲突 | 权限目录将字典查看与部门查看独立定义；字典查询按钮要求字典查看，页面入口却要求部门查看 |
| 实际产物 | 修改字典页面入口条件为字典查看，部门页条件及其余正文保留；副本diff仅一行变化 |
| 关联核对 | 验收已覆盖两项权限互不替代，无需新增平行定义；后续请求仍按当前权限判定 |
| 案例预期 | 仅有字典查看可进入字典页；仅有部门查看不可进入且直接请求拒绝；撤销字典查看后后续请求拒绝 |
| 结果边界 | 本次执行者对真实历史缺陷的定向回放；不是独立盲测、跨项目试用或实现测试 |

### 结构与引用

入仓检查覆盖frontmatter、职能前缀及名称唯一性、维护字段、中文描述、相对引用与锚点、资源可发现性、个人绝对路径和未完成占位。检查结果随本次合并请求说明记录；结构通过不证明行为稳定性。

### 后续迭代

遇到真实遗漏时，记录任务、原始依据、实际产物、预期差异及原因，更新版本并复验对应案例。优先观察是否编造政策、重复追问、遗漏关联输出或超范围修改，不用标题数量、关键词命中或文件生成数量打分。
