# 主流程需求输入契约

前端默认进入新需求页；`?legacy=1` 保留旧审阅页面。新页面连接 `productDevelopmentWorkflow`，创建输入为 `brief/iterationId/guidedIntake:true`。旧输入默认跳过澄清。

流程：方案摘要与显式假设 → 关键问题卡片 → 回答后可再次完善方案 → 完整产品稿 → 版本确认 → 原有项目范围授权。澄清不设总轮数上限，每轮最多八题；逐项检查业务成熟度并经用户显式确认后才进入产品写作，不自动选择推荐答案，不自动批准产品稿。必答项必须有回答；选择以服务端选项 ID 校验，补充答案使用独立文本。回答携带方案 hash、操作者与动作，最终完整稿的 hash 绑定澄清历史。用户确认的是业务选择，不是研发/发布授权。

需求与产品审核页面保留主流程导航，中间阅读方案或完整产品稿，右侧处理当前待决项。需求澄清和开工补充共用受控 `QuestionFlow`：默认逐题，提供上一题/下一题、问题目录、首个未答必答题定位及查看全部；切换模式保留父表单草稿，不自动提交或选择推荐。“展开处理区”切换全宽布局。问题区不限制固定高度，使用页面滚动，窄屏优先展示待办。页面显示当前轮已回答数与必答缺口，不将其解释为需求覆盖度或研发进度；未提交草稿只保存在当前页面内存，刷新不会视为已保存。没有稳定段落引用时不推测问题与方案的精确关联，也不把必答标记包装成阻塞级别评估。完整需求是否充分仍由产品稿审阅确认。

`/intake-api/runs` 创建/列举主 Run，`/intake-api/runs/:runId` 回读，`/intake-api/runs/:runId/respond` 提交澄清或产品批准/拒绝。服务端校验当前步骤、版本、模型模式、完整答案与 Origin 后恢复；页面可刷新恢复当前 Run，不自动重试写操作。状态事实只归 Mastra LibSQL；HTTP 返回的是业务投影。已有生成失败 Run 提供明确状态，可通过 Studio 排查，当前不承诺生成中故障自动续做。

## 远端同步设置

工作台右上角“远端同步设置”管理**后续节点**的交付副本去向：产品与业务澄清、技术方案、开发与评审、测试、发布可分别关闭同步或选择目标仓库。初始默认全部指向 HRM 项目仓库，保持单项目行为。页面会展示每个已登记仓库的远端地址，便于核对“HRM 项目仓库”实际指向；不会泄露本地 checkout 路径。目标仓库只能由实践服务的 `MASTRA_REMOTE_SYNC_TARGETS` 环境变量登记；页面不能新增路径、远端地址或凭据。

“项目仓库管理”页是仓库字典入口，可添加、编辑或移除本机已授权的项目 checkout；保存时服务端核验 Git 根目录与无凭据 HTTPS origin，不会自动 clone、改写代码或推送。阶段页只负责从字典分配去向。也可通过 `MASTRA_REMOTE_SYNC_TARGETS` 作为首次启动的环境初始值。每个目标的 `root` 必须是 Git 根目录且 `origin` 精确匹配登记地址；同步仍使用隔离 Git index 和 `codex/workflow/<根RunId>` 分支。关闭某阶段时，该阶段不创建远端交付副本，Workflow、审批、预算和恢复事实仍由 LibSQLStore 保存。

当前设置的粒度是 Workflow 阶段，动态开发团队内部的前端、后端、工程角色还没有独立的同步节点，不能声称已经支持“按角色分仓”。后续要支持时，应由角色交付产物附带稳定角色路由键，再在服务端目标注册表中设置映射；不接受浏览器提交路径或 Git 配置。

无新增真实身份、跨实例协调、视觉图库或附件能力。固定模式只验证流程，不理解输入。真实质量需要独立业务样本验收。

## 如何区分预算暂停和同步失败

- 模型调用额度耗尽：原生 `recover-development` 关口显示“补充调用额度并继续”，可填写本次追加次数（1–72，默认72），填写确认人并再次确认后追加；累计计数、成功任务和原文件权限保留。
- 历史资料预算失败：门槛已移除，保留原故障事实，从失败角色/阶段直接恢复，不再提交升档决定。新执行使用 Mastra 原生观察记忆，压缩失败不会作为部分成功交付。
- 角色资料同步失败：显示“重试资料同步”，版本及缓存校验后只同步已保存产物，不重新调用模型，不替代产品或开发批准。历史未实施且保存了阻塞架构结果的失败记录通过固定 Time travel 入口恢复；缓存缺失或源码漂移时拒绝重跑。没有恢复入口不等于预算耗尽。

恢复使用已有原生版本hash、源码检查点和身份预检，拒绝过期决定；模型调用追加历史和累计消费持续保留。旧资料档位只为历史快照兼容，新执行不使用它，服务端拒绝新的资料升档参数。恢复指重试当前业务阶段，不代表从模型内部已生成的token继续。

## 问题分类与阻塞依据
