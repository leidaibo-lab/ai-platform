# 竞争格局研究流程

## 工作方法

确定市场和竞品，逐项收集定位、功能、价格与近期变化，建立矩阵和差异化机会；综合威胁，给加码、补齐及忽略建议。

- 开始执行时，用 Mastra 原生 `skill_read` 读取本 Skill 的 `references/upstream.md`，核对完整方法、公式、模板和条件分支；仅按当前任务需要读取附属资料。英文原文保真保留，中文入口负责本宿主的执行适配。
