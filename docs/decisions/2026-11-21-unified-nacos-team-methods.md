# ADR：全团队方法统一由 Nacos 版本化托管

- 状态：接受（用户要求执行抽离；目标环境发布和真实模型质量另验）
- 日期：2026-11-21
- 关联：`2026-11-17-nacos-mastra-resources.md`、`2026-11-21-unified-team-loop-and-project-adapters.md`

## 决策

复用现有只读 Nacos Client Adapter，增加统一方法目录，初始化 Run 一次冻结。产品、研发、测试、浏览器 QA 与共享上下文使用该目录。Git 保留可审查源资产和锁，不与 Nacos 同时成为运行中可替换的方法来源。

不采用各团队独立下载“最新版本”，避免同一 Run 混用版本；不自建方法注册中心。方法文本不获得执行权限，Schema、固定检查、预算、审批与 Mastra Store 事实源继续由宿主实施。新 live Run 缺完整目录拒绝初始化；历史无目录快照继续原方法，不补造新身份。显式关闭 Nacos 供离线验证与兼容，不伪称远端验证。

## 影响与风险

远端资源更新仅影响新 Run；原版本撤销或不可访问则阻止后续模型调用。摘要覆盖 Prompt、Skill 正文、完整 references 与角色绑定。输出只包含安全身份摘要，不导出凭据或将全部方法正文交给模型。准备脚本仅生成待审候选，发布需明确授权。

2026-11-22 用户决定退役旧部署图及其历史 Run，主线以 MR 交付结束。已检查当前默认和独立验证 Store，未发现可识别为旧部署图的快照；未删除其他 Run。

## 验证

专项测试使用真实 ZIP、本机模拟 Nacos、Mastra Store、研发 Workflow 和 Chromium：覆盖资源缺失、目录篡改、角色工具边界、原版本读取、同版本漂移、撤权、Skill 工具调用，以及候选经本机注册器核验和冲突拒绝。类型检查、Mastra 构建、工作台构建、Skill 治理和 OpenSpec 严格验证通过。模拟服务通过不代表目标 Nacos 已发布、真实模型质量或生产验收完成。
