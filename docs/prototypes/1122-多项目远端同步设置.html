需求与产品

读取项目业务规则；在需求与产品落点生成版本化文档。

开发代码

只在授权源码范围生成候选；真实仓库变更仍经过批准、检查和交接。

测试与交接

按受控检查计划生成/执行测试，并交付固定版本回执供下游消费。

接入会登记项目流程配置，不会立即启动 Run。新 Run 冻结项目版本、仓库绑定、落点和权限摘要。

平台自动处理

快速接入聚焦项目差异配置；仓库身份由项目登记提供，技术 Adapter 由平台按识别结果匹配。

可扩展接入 N 个项目

项目通过数据配置接入，不为每个业务工程增加平台代码分支。平台代码只维护通用 Adapter 和安全边界；项目规则、路径和技术策略随项目版本管理。

交付与审批边界

必需 Git 交接不是开关。平台可以生成目录与待确认初稿；业务规则、保护检查和可写范围必须有明确来源并经项目负责人确认，不能由模型直接授权。
