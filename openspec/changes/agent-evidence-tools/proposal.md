# Agent 证据工具

## 目标

为研发和产品角色提供候选变更、代码结构与引用、检查结果、项目资料及外部资料的可追溯查询能力。移除正式产品角色的示例工具，保留最小 Agent 和工具替身评测。

## 边界与待定设计

- 候选查询绑定当前执行作用域、批准基线和候选快照；不得从客户端路径或共享配置推断项目。
- 代码引用结果须说明语言、版本、查询范围及不完整性，不能将文本命中伪装为语义引用。
- 检查查询只投影实际回执，保留来源散列与截断状态。
- 项目资料复用已授权固定版本及现有定位读取机制，不扩大可见范围。
- 外部搜索与网页读取使用可选的 Tavily 服务；每次生成尝试的工具闭包独立限额，仅提取本次搜索结果。工具返回来源、时间和内容摘要；当前不冻结供应商配置或外部正文，恢复后不能假设网页内容不变。
- 不以工具结果替代审批、检查或 Mastra Store 运行事实；保留历史 Run 的兼容性。

代码查询支持 JavaScript/TypeScript 单文件语法分析及候选内跨文件语义引用；未加载依赖或项目编译配置，结果可能不完整。产品阶段及审查的来源回执随 Workflow 状态保存；外部正文与配置版本尚未冻结，真实服务验收仍需完成。
