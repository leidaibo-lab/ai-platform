## ADDED Requirements

### Requirement: 示例工具隔离
正式产品经理和产品审查 Agent SHALL NOT 装配 `practiceInfo` 示例工具。最小 Agent 和独立工具替身评测 MAY 继续使用该工具，且评测 SHALL 使用实际声明该工具的 Agent。

#### Scenario: 产品角色执行
- **WHEN** 创建产品经理或产品审查 Agent
- **THEN** 其工具集不包含 `practiceInfo`
- **AND** 已授权的其他工具不受影响

#### Scenario: 工具替身评测
- **WHEN** 运行工具替身评测
- **THEN** 评测目标使用最小 Agent
- **AND** 替身调用和未声明工具拒绝策略仍可验证

### Requirement: 检查回执定位
研发 Agent MAY 查询当前研发状态中已经保存的检查回执。查询 SHALL 限定当前状态，按回执序号及检查 ID 定位，并返回来源散列、退出状态、截断标记及有界输出片段；不得触发检查或将不存在的回执解释为通过。

#### Scenario: 定位已记录的检查
- **WHEN** 研发 Agent 请求当前状态中的回执序号和检查 ID
- **THEN** 返回该检查的实际记录及来源散列，输出按偏移和长度分页
- **AND** 未知回执或检查明确失败

### Requirement: 受控候选变更和代码查询
研发 Agent SHALL 能在当前执行作用域查询候选文件相对 Run 输入基线的变更及 JavaScript、TypeScript 语法结构和标识符位置。查询 SHALL 绑定项目、基线与当前候选散列；不得访问候选之外的路径，读取期间快照变化 SHALL 失败。输出 SHALL 分页并明确语法匹配不是跨文件语义引用，解析错误 SHALL 显式返回。

#### Scenario: 查看文件变更
- **WHEN** Agent 查询候选或输入基线中的文件
- **THEN** 返回新增、删除或修改的有界 diff 及基线与候选身份
- **AND** 未登记文件及读取期间的候选漂移被拒绝

#### Scenario: 查询代码结构和引用位置
- **WHEN** Agent 查询候选中支持的代码文件及可选标识符
- **THEN** 返回语法节点的位置和类型以及明确的单文件语法匹配范围
- **AND** 不将同名标识符声称为语义绑定的引用

### Requirement: 跨资料检索
交接上下文 SHALL 允许按字面关键词分页检索当前调用登记的资料，结果包含引用 ID、散列与原文位置，正文仍通过登记引用读取。查询 SHALL NOT 扩大当前资料权限。

#### Scenario: 查找关联资料
- **WHEN** Agent 查询关键词
- **THEN** 返回本调用已登记资料的匹配位置与续页游标
- **AND** 未命中只表示已登记资料中的字面匹配结果

### Requirement: 外部资料查询
服务端 MAY 显式配置外部资料服务并向 live 产品角色装配搜索和网页提取工具；未配置或 fixture 模式 SHALL 不访问外网。服务端 SHALL 限制调用次数、超时及响应大小，网页提取 SHALL 仅接受本次搜索返回的 HTTPS 地址。工具结果 SHALL 标记提供方、时间、来源 URL 和内容散列；外部内容为待核实资料，不构成批准需求或执行事实。

#### Scenario: 调研公开资料
- **WHEN** 已配置外部资料服务的产品角色搜索并选择本次结果
- **THEN** 工具返回有界结果和来源信息
- **AND** 未搜索到的地址不得通过提取工具访问

#### Scenario: 外部服务不可用
- **WHEN** 外部服务未配置或请求失败
- **THEN** 不得伪造来源或将缺失结果视作已验证

### Requirement: 候选代码语义引用
研发 Agent MAY 对当前候选中的 JavaScript 和 TypeScript 文件按位置查询语言服务符号引用。语言服务 SHALL 仅使用当前候选快照，不加载宿主依赖；结果 SHALL 返回候选散列、查询范围和已知局限，并对读取期间的漂移失败关闭。

#### Scenario: 符号引用和同名变量
- **WHEN** Agent 查询候选内某一标识符的位置
- **THEN** 返回语言服务识别的候选内引用位置
- **AND** 不将未加载的依赖或其他语言的引用声称为已覆盖

### Requirement: 外部资料来源回执
成功完成的产品阶段和独立审查 SHALL 将实际成功的外部工具结果投影为有界来源回执并保存于对应原生 Workflow 输出；回执 SHALL 区分搜索摘要与网页提取，记录服务、获取时间、来源地址和所用内容散列。来源地址 SHALL 移除查询参数和片段，回执 SHALL NOT 保存密钥或搜索词。历史输出缺少回执时 SHALL 保持可读取，不得补造证据。

#### Scenario: 外部资料成功参与产品阶段
- **WHEN** 产品阶段成功完成且实际收到外部搜索或网页提取工具结果
- **THEN** 阶段输出保存来源回执，并随原生 Workflow 状态恢复
- **AND** 搜索摘要回执不声称网页已被读取

#### Scenario: 工具失败或历史阶段
- **WHEN** 工具失败或历史阶段没有来源回执
- **THEN** 不得补造成功回执
