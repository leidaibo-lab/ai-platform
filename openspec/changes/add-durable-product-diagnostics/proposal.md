## Why

产品诊断目前只能展示角色、模型步骤数和最近活动时间，无法承接阶段目标、输入引用、工具事实、输出结构和失败尝试。前端继续增加展示不会解决后端事实缺失。

本 change 为产品角色产物增加版本化 `product-diagnostic.v1`，让每个新 Run 在同一 Mastra Workflow 快照中保存细粒度执行事实。当前处于开发/测试阶段，不兼容旧历史 Run，旧数据允许删除。

## What Changes

- 为 `productWork.entries` 增加阶段诊断字段：阶段、目标、时间、输入引用、模型统计、工具事实、输出结构、失败尝试和下一步。
- `readIntake()` 从持久化诊断事实生成展示投影，不再由前端或服务端用旧字段猜测详细信息。
- 诊断字段只保存脱敏事实和 Hash，不保存原始 prompt、工具正文或模型私有思维链。
- 暂不新增独立诊断事件表；待事件量、游标读取或跨实例需求出现后再单独重评。

## Capabilities

### Modified Capabilities

- `ai-platform`：产品角色交付物增加版本化细粒度诊断事实。

## Impact

- 产品 Workflow 状态 Schema 和角色产物投影改变。
- 工作台诊断轨迹可以展示真实模型、工具和输出结构信息。
- 开发/测试阶段历史 Run 可删除，不提供旧记录迁移或回退。
