# 全团队方法资源统一到 Nacos

## Why

产品已有远端角色资源，研发与浏览器方法仍依赖本地锁，阶段 Prompt 分散在代码。用户要求所有团队统一托管方法，同时需保留宿主安全边界和历史 Run 身份。

## What Changes

- 统一版本化 Prompt / Skill 绑定与 Run 冻结目录，扩展现有只读 Nacos Adapter。
- 抽离主线角色、任务及共享上下文方法；各团队消费原 Run 快照，调用前校验访问。
- 保持旧快照、本地锁及显式离线模式，不迁移或伪造历史审批。
- 提供离线候选导出、回归与配置文档；不自动发布资源。旧部署图已按后续决定退役。

## Impact

涉及 src/mastra、研发、测试、浏览器 QA、需求回流、共享上下文、nacos-resources、配置及测试。运行事实仍仅由 Mastra Store 持有。
