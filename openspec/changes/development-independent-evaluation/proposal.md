## 背景与目标

独立研发验证应直接使用需求和已登记项目，不依赖产品团队 Run。现有工作台独立研发入口强制产品来源，现有评测脚本又绕过项目范围授权，均不能完整验证研发团队闭环。

## 变更

提供版本化研发独立评测输入，冻结需求正文、散列及项目绑定；使用同一研发团队 Workflow 执行项目范围授权、规划、方案授权、实施、检查、评审和研发交付。评测来源与评测授权不得冒充产品审批或正式交付事实。新入口不提供产品 Run 来源选择；历史 Run 按原契约查看和恢复。真实远端写入仍需单独授权。

## 范围

本变更不修改主业务编排的产品交接，也不降低受保护检查。live 模型调用、业务仓库绑定、实际检查与远端交付分别记录。
